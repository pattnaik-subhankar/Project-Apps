# ReadyHome India — Documentation Set

The 5-document engineering set for the ReadyHome disaster-preparedness app, written in the
"5 documents before building an AI app" framework. Every doc is grounded in the live v1
build (github.com/pattnaik-subhankar/Project-Apps, deployed on GitHub Pages).

| # | Doc | One-liner |
|---|---|---|
| 01 | [PRD](01-PRD.md) | What it is, who it's for, what shipped, success metrics |
| 02 | [Technical Architecture](02-Technical-Architecture.md) | Zero-backend static SPA: components, decisions, evolution path |
| 03 | [System Design](03-System-Design.md) | Flows, data model, failure modes, performance budget, security |
| 04 | [Frontend Spec](04-Frontend-Spec.md) | Design tokens, components, responsive rules, accessibility, QA checklist |
| 05 | [Feature Tickets](05-Feature-Tickets.md) | Shipped P0 tickets w/ acceptance criteria + P1/P2 backlog |

Also in the app itself: the **7-step "How it works" guide** (numbered step cards with
illustrations) lives directly on the homepage.
